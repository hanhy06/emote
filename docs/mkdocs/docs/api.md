# Mod API

`EmoteApi.getInstance()`를 통해 다른 서버 모드에서 Emote 기능을 사용할 수 있습니다.

현재 API가 제공하는 주요 기능은 다음과 같습니다.

- 런타임 이모트 등록 및 해제
- 플레이어 이모트 재생과 중지
- 현재 재생 상태 조회
- 취소 가능한 재생 요청 리스너
- 재생 시작·종료 생명주기 리스너

상태를 변경하는 API 호출은 Minecraft 서버 스레드에서 실행해야 합니다. 런타임에 등록한 이모트는 `/emote reload` 이후에도 유지됩니다.

!!! note "초안"
    패키지별 타입과 메서드 예제는 공개 API가 확정된 뒤 이 페이지에 추가합니다. 현재는 저장소의 `io.github.hanhy06.emote.api` 패키지를 기준으로 확인하십시오.
