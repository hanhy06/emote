# Emote

Emote는 Minecraft 디스플레이 엔티티로 애니메이션을 재생하는 서버 측 Fabric 모드입니다. 서버에만 설치해도 모든 서버 기능을 사용할 수 있으며, 클라이언트 설치는 이모트 휠과 재생 중 자동 3인칭 전환 기능을 추가합니다.

[Modrinth](https://modrinth.com/mod/emote){ .md-button }

## 주요 기능

- BD Engine, GeckoLib, Animated Java 프로젝트를 Animation JSON으로 변환
- 플레이어 스킨 파츠, 재생 설정, 중단 조건 및 프레임 명령 설정
- 여러 애니메이션을 연결하는 Sequence와 2인 협동 이모트
- LuckPerms 권한별 이모트와 유휴 이모트 구성
- 다른 모드에서 재생과 이벤트를 제어할 수 있는 서버 API
- 선택적으로 설치하는 클라이언트 이모트 휠
